# PacketDelay
Simple mod that delays packets and sends them all when the keybind is released

Delays these following packets: 

`ServerboundPlayerActionPacket`

`ServerboundPlayerInputPacket`

`ServerboundUseItemOnPacket`

`ServerboundUseItemPacket`

`ClientboundSetHeldSlotPacket`

`ServerboundInteractPacket`

**Useful for explosionless bedrock breaking!**

<a href="https://modrinth.com/mod/packet-delay">
        <img alt="modrinth" height="40" src="https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3/assets/compact/available/modrinth_vector.svg">

## Usage
Set a keybind for delaying packets

Hold down the keybind to delay packets

Release the keybind to send the packets

## Dependencies
Requires [Fabric API](https://modrinth.com/mod/fabric-api)
